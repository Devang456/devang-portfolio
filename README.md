## 🚀 Getting Started Locally

### Prerequisites
* [Node.js](https://nodejs.org/) (v18.0 or higher recommended)
* npm (v9.0 or higher)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Devang456/devang-portfolio.git
   cd devang-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Run linter:
   ```bash
   npm run lint
   ```
